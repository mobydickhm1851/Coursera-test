白話術語速查

不用先背。遇到題目再回來看。
Fork / 雙攻

一顆棋同時攻擊兩個目標，讓對手通常只能救一個。

Pin / 牽制

前面的棋子不敢動，因為一動就會露出後面更重要的棋子，常見是王。

Skewer / 串擊

先攻擊前面的高價值目標，逼它移開，再吃後面的棋。

Passed pawn / 通路兵

往升變方向的前方與左右相鄰 file，都沒有敵兵能正常攔它。

Isolated pawn / 孤兵

左右相鄰 file 都沒有自己的兵，因此缺少兵的互相保護。

Doubled pawns / 疊兵

同一條 file 上有兩顆自己的兵。

Outpost / 前哨站

深入敵方、能站穩、又很難被敵兵趕走的好格子，騎士尤其喜歡。

Tempo

可以把它想成「一步的時間」。浪費一步，就是讓對手多一個發展機會。
